# 売上・成約 集計ダッシュボード セットアップ手順

## 全体の仕組み

```
[スプレッドシート] --(A) GASが読み取り--> [GAS Web App(API)]
                                              ↑
                                    (B) ボタンを押すとfetch
                                              ↓
                            [WEBページ (GitHub Pages)] index.html / style.css / app.js
```

- GASはページを表示しません。「スプレッドシートを読んでJSONを返すAPI」としてのみ動作します。
- WEBページ側の「最新データを取得」ボタンを押した時だけ、そのAPIを呼び出してデータを取り込みます（更新は任意タイミング）。
- 一度取得したデータはブラウザに保存されるので、次回アクセス時もボタンを押すまでは前回のデータが表示されます。

---

## 手順1: Google Apps Script のデプロイ

1. スプレッドシートを開く → メニュー「拡張機能」→「Apps Script」
2. 左側のファイル一覧で「+」→「スクリプト」から新しいファイルを追加し、ファイル名を `DashboardApi` にする
   （既存の `Code.gs` はそのまま残してOKです。今回のスクリプトは別ファイルとして追加します）
3. 追加した `DashboardApi.gs` に、このリポジトリの **`DashboardApi.gs`** の内容を貼り付ける
   - スプレッドシートID・シート名は指定の内容で設定済みです。変更不要です。
   - 同じプロジェクト内に複数の `.gs` ファイルがあっても問題ありません。`doGet` 関数が重複していなければ共存できます。
   - もし既存の `Code.gs` 側にも `doGet` 関数が定義されている場合は関数名が衝突するため、`DashboardApi.gs` 側の `doGet` を `doGet_dashboard` などにリネームし、デプロイ時にどちらを使うか整理してください（通常は1プロジェクトにつき `doGet` は1つだけ有効です）。
4. 画面右上「デプロイ」→「新しいデプロイ」
   - 種類の選択（歯車アイコン）→「ウェブアプリ」
   - 説明: 任意（例: 売上ダッシュボードAPI）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 「デプロイ」をクリック → 初回は権限の承認画面が出るので、自分のGoogleアカウントで許可
6. 発行された **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxxx/exec` の形式）をコピー

> スプレッドシートの中身を更新した場合、この再デプロイは不要です。データが変わったらWEBページ側の「最新データを取得」ボタンを押すだけで反映されます。

---

## 手順2: app.js にURLを設定

`app.js` の1行目付近にある以下を、手順1でコピーしたURLに書き換えます。

```js
const GAS_URL = 'ここにGAS Web App の URL を貼り付け';
```

↓

```js
const GAS_URL = 'https://script.google.com/macros/s/xxxxxxxxxxxxx/exec';
```

## 手順3: GitHubにアップロード

1. GitHubリポジトリを作成（未作成の場合）
2. `index.html` / `style.css` / `app.js` の3ファイルをリポジトリ直下（または `/docs` フォルダ）にアップロード
   - `DashboardApi.gs` と `README.md` はGitHub Pagesの公開には不要ですが、管理用に一緒に置いておいてOKです
3. リポジトリの「Settings」→「Pages」
   - Source: `Deploy from a branch`
   - Branch: `main` / `root`（`/docs` に置いた場合は `docs` フォルダを選択）
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でページが公開されます

> **重要:** GitHub Pagesを無料プランで使う場合、リポジトリは **Public** である必要があります。社外に見られたくないデータの場合は、
> - GitHub Team/Enterpriseプランで Private リポジトリ + Pages を使う
> - もしくは社内ネットワークのみでアクセスできる別ホスティング（社内サーバー等）を検討する
>
> ことをおすすめします。この点は運用開始前に必ずご確認ください。

## 使い方

1. 公開されたページを開く
2. 初回は「最新データを取得」ボタンを押してスプレッドシートのデータを取り込む
3. 上部のフィルタ（日付範囲・仲介・屋号・店舗名・地方・都道府県）で絞り込み
4. KPIカード（売上合計・BP件数・成約数）が自動で更新される
5. 「店舗別集計」タブ・「明細データ」タブで表を切り替え、各列見出しをクリックすると高い順/低い順にソート
6. スプレッドシートを更新した後は、再度「最新データを取得」ボタンを押すと反映されます

## カスタマイズ可能な項目

- **「NG店舗を除外する」チェックボックス**: AI列（NG店舗）の値が `NG` / `1` / `TRUE` / `対象` のいずれかに該当する行を除外する想定で実装しています。実際の入力ルールと異なる場合は `app.js` の `isNgShop()` 関数を調整してください。
- **店舗別集計の単位**: 現在は「店舗名 + 屋号」を1グループとして集計しています。集計単位を変えたい場合は `app.js` の `buildGroups()` を調整してください。
- **1ページの表示件数**: `app.js` 冒頭の `PAGE_SIZE`（デフォルト50件）で調整できます。

---

## データ量について

10万件規模でも、ブラウザ側での絞り込み・集計・ソートは問題なく動作する設計です（明細データの一覧表示のみページング表示にして描画負荷を抑えています）。ただし、初回のデータ取得（GASからの読み込み）はデータ量に応じて数秒〜数十秒かかる場合があります。
